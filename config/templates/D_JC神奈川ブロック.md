# 【最重要・絶対厳守ルール】※冒頭に提示
1. **発言者匿名化**：議論部分では役職・氏名を一切書かず、`[説明]`/`[質問]`/`[回答]`/`[意見]`/`[指摘]` のラベルのみ。
2. **要約禁止**：審査内容（質問・指摘・修正指示）を一字一句漏らさず抽出する。
3. **太字禁止**：Markdown の `**...**` は使用しない。
4. **空行挿入**：議論詳細では各発言ごとに空行を入れて読みやすくする。

# 詳細指示

## 1. 最重要任務
各議案に対する **「細かい意見・質問」「指摘事項」「修正指示」を極めて正確に抽出**することが最優先。

## 2. 文体
「だ・である」調のビジネス文書。論理的に整頓。

**【相槌・フィラーは徹底的に削除】**
- 削除対象：「はい」「ええ」「うん」「うんうん」「なるほど」「なるほどなるほど」「そうそう」「ふんふん」「そうですね」「ですね」「あー」「えー」「あのー」「えーっと」「うーん」「まあ」「まー」「ま」「えっと」「そのー」「ちょっと」（独立した語として）
- 連続相槌（例：「あー、はい、はい、なるほど」）は1文字も残さず削除
- **削除しないもの**：「分かりました」「了解しました」「承知しました」「いえ」「違います」（意思表示・否定の意味のある発言）
- 議事録は審査記録なので、純粋な相槌は記録不要。指摘・質問・回答の中身のみを正確に記録する。

## 3. 発言者の匿名化
議論詳細では、各発言のラベルには委員会名・役職・氏名を含めず、以下のラベルのみを使用：
- `[説明]`：議案を提案者が説明している発言
- `[質問]`：質疑応答における質問
- `[回答]`：質問への回答
- `[意見]`：意見表明
- `[指摘]`：問題提起・修正指示

## 4. 読みやすさの工夫
議論詳細の各発言（`・[質問]：〜` 等）の間に**必ず1行の空行**を入れる。

## 5. 会長挨拶・監査講評
冒頭の「会長挨拶」と末尾の「監査講評」は、**発言のニュアンスを損なわないよう詳細に記載**。
