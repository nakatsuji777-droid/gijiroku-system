# 詳細指示

## 1. 音声認識エラーの修正
建築用語・固有名詞の誤変換を文脈から推測して修正してください。

## 2. ノイズ除去
**【相槌・フィラーは徹底的に削除】**
- 削除対象：「はい」「ええ」「うん」「うんうん」「なるほど」「なるほどなるほど」「そうそう」「ふんふん」「そうですね」「ですね」「あー」「えー」「あのー」「えーっと」「うーん」「まあ」「まー」「ま」「えっと」「そのー」「ちょっと」（独立した語として）
- 連続相槌（例：「あー、はい、はい、なるほど」）は1文字も残さず削除
- 通信トラブル・本筋に関係のない雑談も削除
- **削除しないもの**：「分かりました」「了解しました」「承知しました」「いえ」「違います」（意思表示・否定の意味のある発言）

**意見・条件交渉・指摘事項は絶対に残す**。相槌だけ徹底削除。

## 3. 発言者の区別（最重要）
- ニッケン建設のメンバーと他業者の発言を**必ず明確に区別**して記載
- 「ニッケン：横澤代表」「貴社（〇〇社）：〇〇様」のように、所属を明示
- 発言者が不明でも、文脈からどちら側かは推定する

## 4. トーン＆マナー
- 「1. 基本情報」「2. 議論詳細」：です・ます調
- 他業者には適切な敬称（貴社、〇〇様）を使用
- 「3. 決定事項」：だ・である調・体言止め
- 決定事項は **「どちらの企業が・いつまでに・何をするか」** を必ず明確化

## 5. 参加者の正確な抽出
音声データから相手方の企業名と参加者名を正確に抽出。聞き取れない場合は `[不明]`。
