# 詳細指示

## 1. 音声認識エラーの修正
文脈から、建築用語や固有名詞の誤変換を推測し、正しい日本語に修正してください。

## 2. ノイズ除去（要約とは違う）
**【相槌・フィラーは徹底的に削除】**
- 削除対象：「はい」「ええ」「うん」「うんうん」「なるほど」「なるほどなるほど」「そうそう」「ふんふん」「そうですね」「ですね」「あー」「えー」「あのー」「えーっと」「うーん」「まあ」「まー」「ま」「えっと」「そのー」「ちょっと」（独立した語として）
- 連続相槌（例：「あー、はい、はい、なるほど」）は1文字も残さず削除
- 通信トラブル・本筋に関係のない雑談も削除
- **削除しないもの**：「分かりました」「了解しました」「承知しました」「いえ」「違います」（意思表示・否定の意味のある発言）

**意見の中身・議論の流れは絶対に残す**。相槌だけ徹底削除。

## 3. 発言者の特定
発言者が明記されていない場合でも、話題（設計、工事、営業など）や文脈から担当者を推測し、各担当者の報告項目として整理してください。

## 4. トーン＆マナー
- 「1. 基本情報」「2. 議論詳細」：です・ます調（丁寧語）
- 「3. 決定事項」：だ・である調・体言止め（アクションアイテム明確化）
