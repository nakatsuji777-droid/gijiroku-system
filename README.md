# 議事録作成システム

ニッケン建設 / JC神奈川ブロックの会議音声から、会議種別に応じた議事録を自動生成するローカルアプリです。

---

## 主な機能

- **5種のテンプレート切替**：会議種別に応じた議事録フォーマット・トーン・ラベルを自動適用
  - A：ニッケン建設 社内会議用
  - B：SNS広報戦略会議用
  - C：他社会議用
  - D：JC神奈川ブロック コンプライアンス審査用
  - E：汎用議事録（NotebookLM互換）
- **音声ファイル → 議事録の一気通貫処理**：Whisper で文字起こし → Claude で整形
- **文字起こしテキストの直接入力にも対応**：既に別ツールで文字起こし済みの場合も利用可
- **文字起こし結果の編集**：生成前に誤変換を手動修正可能
- **生成結果のプレビュー＆ダウンロード**：Markdown / プレーンテキスト形式で出力
- **過去の議事録の一覧・検索**：保存済み議事録を会議種別・日付範囲・キーワードで絞り込み
- **自動ファイル名衝突回避**：同日複数会議でも時刻付きファイル名で自動的に分離保存
- **状態リセット機能**：サイドバーの「新規作成」ボタンで一発クリア
- **APIキー・入力状態の可視化**：生成前に準備状況を一目で確認可能

## セットアップ手順（初回のみ）

### 1. Python のインストール

[Python公式サイト](https://www.python.org/downloads/) から **Python 3.10 以上** をダウンロード・インストールしてください。

インストール時、**「Add Python to PATH」にチェックを入れる**のを忘れないでください。

### 2. Anthropic API キーの取得

1. [Anthropic Console](https://console.anthropic.com/) にサインアップ
2. API キーを発行
3. `.env.example` を `.env` にコピーし、`ANTHROPIC_API_KEY=` の後ろにキーを貼り付け

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxx
```

### 3. 初回起動

`起動.bat` をダブルクリックしてください。初回は以下を自動で行います。

1. Python 仮想環境（`.venv`）の作成
2. 依存パッケージ（streamlit, anthropic, faster-whisper 等）のインストール
3. Streamlit アプリの起動

初回は5〜10分ほど時間がかかります。
2回目以降はすぐに起動します。

ブラウザで http://localhost:8501 が自動で開けば成功です。

## 使い方

### 新規作成フロー（「議事録生成」タブ）

1. **起動.bat をダブルクリック**
2. ブラウザが開いたら、左サイドバーで **会議種別（A〜E）** を選択
3. **1. 入力**エリアで音声ファイルをアップロード、または文字起こしテキストを貼り付け
4. 音声ファイルの場合は **「文字起こしを実行」** ボタンを押して待機（長時間音声は数分〜）
5. 必要に応じて文字起こし結果を編集
6. **2. 会議情報**（日時・場所・出席者）を任意で入力
7. 「文字起こし」と「APIキー」の両方が準備完了になったら、**「議事録を生成」** ボタンを押下
8. 生成結果を確認し、**ダウンロード** ボタンで保存

連続作成する場合は、サイドバーの **「新規作成（状態をリセット）」** ボタンで入力をクリアできます。

### 過去の議事録を探す（「過去の議事録」タブ）

1. 上部タブで **「過去の議事録」** を選択
2. 以下の条件で絞り込み可能
   - **会議種別**（A〜E 単独）
   - **キーワード**（ファイル名・本文の部分一致）
   - **開催日の範囲**（開始日・終了日）
3. 一覧の各行を展開するとプレビュー・ソース表示・ダウンロードが可能

### 生成済み議事録の保存先

`output/` フォルダに `議事録_[テンプレートID]_[日付]_[時刻].md` の名前で自動保存されます。
（例：`議事録_A_2026-04-12_1423.md`）

同日中に複数会議を処理しても、時刻が含まれるためファイル名が衝突しません。

## カスタマイズ方法

### 新しい会議種別を追加する

1. `config/templates/` に新しいテンプレート `.md` ファイルを作成
   - 末尾に `{metadata}` と `{transcript}` プレースホルダを含めること
2. `config/templates.json` に新しいエントリを追加

```json
{
  "F": {
    "name": "新しい会議種別名",
    "description": "会議の説明",
    "file": "F_新しい会議.md",
    "output_format": "markdown"
  }
}
```

3. アプリを再起動すると選択肢に反映されます

### テンプレートの内容を編集する

`config/templates/` 配下の `.md` ファイルを直接編集してください。誤変換辞書の追加・参加者マスタの更新もこちらで行います。

### Whisper モデルサイズを変更する

`src/config.py` の `whisper_model_size` を変更してください。

| モデル | 速度 | 精度 | 用途 |
|---|---|---|---|
| `tiny` | 最速 | 低 | デバッグ用 |
| `base` | 速 | やや低 | 簡易確認 |
| `small` | 中 | 中 | バランス |
| `medium` | やや遅 | 高 | 実用 |
| `large-v3` | 遅 | 最高（日本語推奨） | 本番 |

CPU環境では `medium` または `small` の方が実用的な場合もあります。

## トラブルシューティング

### 「Python がインストールされていません」と表示される
- Python を再インストールし、**「Add Python to PATH」**にチェックを入れてください

### 「ANTHROPIC_API_KEY が設定されていません」と表示される
- プロジェクトルートに `.env` ファイルがあるか確認
- `.env` ファイル内で `ANTHROPIC_API_KEY=sk-ant-...` と正しく書かれているか確認

### 文字起こしが極端に遅い
- `src/config.py` の `whisper_model_size` を `medium` または `small` に変更
- もしくはGPU搭載PCで `whisper_device = "cuda"`、`whisper_compute_type = "float16"` に変更

### 議事録の内容が要約されすぎている
- Claude モデルを `claude-opus-4-6` にしていることを確認
- テンプレート本文の「8〜9割保持ルール」が残っているか確認
